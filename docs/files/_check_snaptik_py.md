# _check_snaptik.py (công cụ kiểm thử/phụ trợ)

- Mục đích: Targeted SnapTik checks: rights gate, DOWNLOAD_FAILED, media inspection.
- Hàm chính: `check`
- Đầu vào: tham số dòng lệnh/mặc định trong file; không chạm dữ liệu người dùng khi chạy đúng cách.
- Tác động: chỉ đọc/ghi file tạm hoặc state kiểm thử; không tải media, không đăng bài, không build EXE.
- Cách chạy: `py _check_snaptik.py` (chỉ chạy khi nhiệm vụ yêu cầu; nhiệm vụ tài liệu KHÔNG chạy).
- Mã nguồn trên GitHub: [_check_snaptik.py](https://github.com/doansensei1503-maker/TOOLTDH/blob/main/_check_snaptik.py)
