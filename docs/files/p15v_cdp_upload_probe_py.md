# p15v_cdp_upload_probe.py (công cụ kiểm thử/phụ trợ)

- Mục đích: P15V probe: can a large file be set through the raw CDP session?
- Hàm chính: `probe`
- Đầu vào: tham số dòng lệnh/mặc định trong file; không chạm dữ liệu người dùng khi chạy đúng cách.
- Tác động: chỉ đọc/ghi file tạm hoặc state kiểm thử; không tải media, không đăng bài, không build EXE.
- Cách chạy: `py p15v_cdp_upload_probe.py` (chỉ chạy khi nhiệm vụ yêu cầu; nhiệm vụ tài liệu KHÔNG chạy).
- Mã nguồn trên GitHub: [p15v_cdp_upload_probe.py](https://github.com/doansensei1503-maker/TOOLTDH/blob/main/p15v_cdp_upload_probe.py)
